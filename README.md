# Educational Departmental Platform

A modern web application for managing methodological recommendations and generating reports for university department staff.

## 🚀 Technologies Used

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL

## 📋 Features

- Management of methodological recommendations
- Generation of personalized reports for teachers
- User-friendly web interface
